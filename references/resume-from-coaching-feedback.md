# 从辅导对话提取简历修改建议并执行

## 适用场景
用户（辅导老师/教练）有一段与学员的辅导对话记录，需要从中提取简历修改要点，并应用到学员的简历文件上。

## 工作流程

### Step 1: 读取对话记录，提取修改要点
从对话文本中识别并分类：
- **内容问题**：缺少数据、经历不够、含金量不足
- **语言问题**：过于口语化、不像简历语言
- **结构问题**：缺少小标题、自我评价连成一坨
- **补充需求**：需要从其他来源补充课程/项目经历
- **格式要求**：用户明确的格式偏好（如小标题结构）

### Step 2: 读取当前简历文件
- 读取学员的当前简历（docx/pdf）
- 了解现有内容和结构

### Step 3: 交叉参考补充来源
- 用户可能提供额外的源文件（PDF简历、课程清单等）
- 用 pymupdf 提取 PDF 文本：`/c/Users/MECHREVO/AppData/Local/Python/pythoncore-3.14-64/python.exe -c "import fitz; ..."`
- 注意：read_file 对 PDF 返回二进制乱码，必须用 pymupdf
- 注意：vision_analyze 不支持 PDF 文件，只支持图片

### Step 4: 列出修改计划（必须！）
在执行任何修改前，先列清单展示：
1. 所有修改项（编号）
2. 每项的具体操作
3. 输出格式和路径

**等用户确认后再执行。** 这是数据操作纪律。

### Step 5: 执行修改
- 用 python-docx 生成 Word 文件
- 格式：纯文字 + 加粗标题 + 圆点列表，无表格/边框/颜色
- 字体：微软雅黑 + CalCalibri

## 常见修改类型

### 1. 补充金融/专业课程经历
从教育背景的核心课程中提取，包装为项目经历：
- 选取与目标岗位相关的课程（如金融销售→财务报表分析、估值建模）
- 包装为课程项目：课程名 + 做了什么 + 产出/成果
- 如原始成绩不突出，适度包装但不失真

### 2. 实习经历扩展+数据补充
- 扩写职责描述，增加量化数据
- 用专业书面语言重写

### 3. 口语化表述书面化
常见口语化表达 → 专业表述对照：
- ❌ "自己找选题、写文案、盯数据" → ✅ "独立负责内容选题策划、文案撰写及数据监测"
- ❌ "我主动联系他们，拿社群用户画像说服他们" → ✅ "基于社群用户画像分析，主动对接合作方并达成资源置换合作"
- ❌ "建了二手物品售卖群" → ✅ "搭建二手物品交易社群"

### 4. 个人优势总结格式（替代自我评价）

用户偏好「个人优势总结」格式。**严格遵循此格式**：

```
个人优势总结
**金融专业基础扎实:**金融管理本科+企业金融硕士，系统学过财务报表分析、估值建模、并购收购等课程，能看懂财报、算得清估值。
**有机构客户服务经验:**在兴业证券实习期间参与50+机构客户对接与30余场路演执行，了解券商销售从研究到路演的完整流程，入职后可快速上手。
**工作技能:**Excel财务建模、Python金融建模、MS Office、剪映视频剪辑、英语可作为工作语言。
```

规则：
- 每行一个特质：**加粗小标题**:1-2句简洁描述（同一行，无换行，无圆点）
- 小标题选取目标岗位青睐的特质（金融销售→专业基础、客户沟通、执行力、协调能力、抗压自驱）
- 描述要具体有数据，不要泛泛而谈（❌"善于倾听需求" → ✅"参与50+机构客户对接"）
- 最后一行为「工作技能」汇总
- **不要**用圆点列表，**不要**拆成多行，**不要**连成一坨
- **不要**用过于冗长的描述（如"拥有...系统学术训练，核心课程涵盖...具备...知识储备"）

### 5. 课程项目经历包装

当专业实习经历单薄时，将核心课程包装为独立项目经历。

**精简原则（用户明确要求"课程项目不用太细"）：**
- 每个项目 2 条 bullet 即可，不需要分子标题展开
- 不需要末尾「能力映射」——那是过度包装
- 保留核心数据（报告字数、评分排名、回测结果），去掉过程描述
- 2-3门相关课程合并为一个项目，不要一门课一个项目

**正确示例：**
```
## 金融课程项目经历
### 财务报表分析与企业估值项目　课程独立项目　2025.09 – 2025.12
• 选取某消费赛道A股上市公司，通过Wind收集近三年财报，从盈利、偿债、运营三个维度进行同业与历史对比分析。
• 独立搭建DCF模型，并用可比公司法进行交叉验证，最终撰写3000字投资价值分析报告，课程评分位列前15%。
```

**错误示例（过度展开）：**
```
### 财务报表分析与企业估值项目　课程独立项目　2025.09 – 2025.12
**研究框架与数据收集**
• 选定XX公司作为研究标的，通过Wind等数据源收集近三年财务报告...
**估值建模与投资逻辑**
• 独立搭建DCF折现现金流模型...
**能力映射**
• 通过该项目建立了从财务数据到投资判断的完整分析链路...
```

### 6. 小标题结构（底线要求）

所有经历板块必须有小标题组织内容。按能力维度/工作模块划分：
- 券商实习：「客户对接与关系维护」「路演统筹与项目协调」「研究支持与信息提炼」「销售支持与团队协作」
- 新媒体实习：「新媒体矩阵运营」「私域社群搭建与转化」「线下活动策划与获客」
- 校园创业：「社群运营与团队管理」「商务合作与渠道拓展」

小标题命名原则：按能力维度划分，不用序号。

### 7. 关键经历扩张原则

候选人最贴近目标岗位的经历要重点扩张（如 ToB 金融销售→券商实习从4条扩到12条，分4个小标题）。其他经历保持精简。

迭代模式：v2（基础版）→ v2.1（格式修正）→ v2.2（关键经历扩张）→ v2.3（课程项目细化）
