# 简历优化指南 — ToB 销售方向

## 适用场景

用户带简历来优化，目标是 ToB 销售岗位（金融、SaaS、工业等）。

## 核心原则

### 1. 只改实质内容，不改格式样式
- 用户自己决定留哪些板块、用什么格式
- 不要主动加教育背景、自我评价、兴趣爱好等装饰性板块
- 不要主动调整排版、字体、颜色
- 用户说"去掉xx"就直接去掉，不要劝留

### 2. STAR 法则融入自然段落
**正确写法（自然叙述）：**
> 部门每周安排 3-5 场路演，研究员和客户时间经常撞。我独立协调两边的时间，做路演日程表实时更新，碰到冲突就主动拉线上参会或者调场次，实习期间一共协调了 30+ 场，没出过一次排期问题，客户参会率比之前高了大概 15%

**错误写法（AI标签拆开）：**
> - **路演协调执行（STAR）：**
>   - *背景：* 部门每周需安排 3-5 场机构路演...
>   - *行动：* 独立对接研究员与机构客户双方时间...
>   - *结果：* 实习期间累计协调路演 30+ 场...

禁止使用"背景/行动/结果"标签。STAR 是写作思路，不是格式模板。

### 3. 去 AI 味道

**禁用词/短语：**
- 闭环、赋能、沉淀、抓手、链路、颗粒度
- 精准触达、高效转化、持续获取、深度挖掘
- 支撑...运转、保障...一致、确保...闭环
- 从 0 到 1（除非用户自己用过）
- 通过优质内容持续获取精准流量
- 搭建标准化分析框架、转化链路设计（过于书面化，换成"进行对比分析"、"转化路径"）

**禁用结构：**
- 每条都用 `**粗体标签：**` 开头的完美并列
- 四条以上完全对称的句式
- 每句话都以动词开头的整齐排列

**正确做法：**
- 可以用"我"来讲，像自己在叙述
- 句子长短不一，有的长有的短
- 口语化表达："拿数据说服他们给资源" 而非 "通过展示数据说服对方提供资源"
- 数据保留，但包装去掉："涨粉 3w+" 而非 "通过优质内容实现全平台粉丝增长 3w+"

### 4. 经历翻译 — 用销售语言重写

| 原始表述 | 翻译后（ToB 销售视角） |
|---------|----------------------|
| 运营社群 2000+ 人 | 自主运营 4 个社群共 2000+ 人，组建 8 人团队 |
| 和高顿合作引流 | 主动联系高顿商务，拿用户画像说服对方给资源和奖金 |
| 安排路演行程 | 协调研究员和客户的时间冲突，累计 30+ 场零差错 |
| 写研究报告摘要 | 每周读 5-8 篇研报，提核心逻辑整理成销售团队能用的材料 |

### 5. 说服案例 — 从聊天记录提取

学生讲的口语化案例，要翻译成简历语言但保留细节：
- "联系班长→班长介绍宿舍长" → 保留这个链路，这是真实的销售路径
- "外强中干的客户不能直接说" → 翻译为"针对不同性格调整沟通策略"
- "拉到一次体验课就是 600 块" → 翻译为具体数据（引流 600+，成交 10 单，奖金 6000）

## 工作流程

1. 读简历原文，提取所有经历的原始数据
2. 读聊天记录/图片，提取口语化的细节和案例
3. 用销售语言重写每段经历，STAR 自然融入
4. 去掉 AI 味道：检查禁用词、完美并列、过度包装
5. 检查是否需要补充课程项目经历（实习单薄时必须加）
6. 检查是否需要扩展关键经历（最贴近目标岗位的扩张）
7. 检查所有板块是否有小标题
8. 口语化检查：逐行扫描中文口语表达（见下方清单）
9. 生成 Word（python-docx，纯文字+加粗+圆点列表）
10. 清理文件元数据，移除 AI 痕迹（见下方代码）
11. **直接覆盖原文件**，不要另存为 v2/v3 等版本

## 口语化检查清单

生成简历后逐行扫描，以下表达必须替换：

| 口语化 | 替换为 |
|--------|--------|
| 涨粉 | 粉丝增长 |
| 能看懂财报、算得清估值 | 具备财务报表分析与估值建模的实操能力 |
| 做过xx | 具备xx实操经验 |
| 能扛事 | 适应高强度多线程工作 |
| 搞定了 | 完成/达成 |
| 跟xx打了交道 | 对接/服务xx |

**同时检查：**
- 主观评价（如"获带教老师'细致靠谱'评价"）→ 换成具体行为描述
- "我..."开头的句子 → 去掉"我"或改为被动/省略主语
- 弱证明（如"同时承担硕士在读与求职双线任务"来证明时间管理能力）→ 这是所有应届生的常态，不算特别证明。要么删掉，要么换成具体行为（如"面对多线程任务时习惯拆解优先级、按节点推进落地"）
- 个人优势总结各条长度应相近，不要某条突然变短（用户会注意到视觉不一致）

## 元数据清理

python-docx 生成的文件会带 AI 痕迹（author: python-docx, comments: generated by python-docx），必须清理：

```python
from docx import Document
from docx.opc.constants import RELATIONSHIP_TYPE as RT

doc = Document(path)
cp = doc.core_properties
cp.author = ''
cp.last_modified_by = ''
cp.comments = ''

# 清理底层 XML
core_props_part = doc.part.package.part_related_by(RT.CORE_PROPERTIES)
core_xml = core_props_part._element
ns = {'cp': 'http://schemas.openxmlformats.org/package/2006/metadata/core-properties',
      'dc': 'http://purl.org/dc/elements/1.1/',
      'dcterms': 'http://purl.org/dc/terms/'}
for tag in ['dc:creator', 'cp:lastModifiedBy', 'cp:revision', 'dcterms:created', 'dcterms:modified']:
    prefix, local = tag.split(':')
    for elem in core_xml.findall(tag, ns):
        core_xml.remove(elem)

doc.save(path)
```

验证：`doc.core_properties.author` 应为空，`comments` 应为空。

## 课程项目经历包装

当金融/销售相关实习经历单薄时，从核心课程中提取，包装为独立项目经历。

**精简原则（用户明确要求"课程项目不用太细"）：**
- 每个项目 2 条 bullet 即可，不需要分子标题展开
- 不需要末尾「能力映射」——那是过度包装
- 保留核心数据（报告字数、评分排名、回测结果），去掉过程描述
- 2-3门相关课程合并为一个项目，不要一门课一个项目

**正确示例：**
> 财务报表分析与企业估值项目　课程独立项目　2025.09 – 2025.12
> • 选取某消费赛道A股上市公司，通过Wind收集近三年财报，从盈利、偿债、运营三个维度进行同业与历史对比分析。
> • 独立搭建DCF模型，并用可比公司法进行交叉验证，最终撰写3000字投资价值分析报告，课程评分位列前15%。

**错误示例（过度展开）：**
> • 研究框架与数据收集：选定消费赛道某A股上市公司作为研究标的...
> • 估值建模与投资逻辑：独立搭建DCF折现现金流模型...
> • 能力映射：通过该项目建立了从财务数据到投资判断的完整分析链路...

## 小标题结构（底线）

所有经历板块必须有小标题，按能力维度/工作模块划分：
- 券商实习：「客户对接与关系维护」「路演统筹与项目协调」「研究支持与信息提炼」「销售支持与团队协作」
- 新媒体实习：「新媒体矩阵运营」「私域社群搭建与转化」「线下活动策划与获客」

## 关键经历扩张原则

最贴近目标岗位的经历重点扩张（如金融销售→券商实习从4条扩到12条，分4个小标题）。其他经历保持精简。

## 个人优势总结格式

替代传统自我评价。**严格遵循此格式**：

**格式：** `**加粗小标题**:1-2句简洁描述`（同一行），末尾工作技能汇总。

**正确示例（简洁版）：**
> **金融专业基础扎实:**金融管理本科+企业金融硕士，系统学过财务报表分析、估值建模、并购收购等课程，能看懂财报、算得清估值。
> **有机构客户服务经验:**在兴业证券实习期间参与50+机构客户对接与30余场路演执行，了解券商销售从研究到路演的完整流程，入职后可快速上手。
> **工作技能:**Excel财务建模、Python金融建模、MS Office、剪映视频剪辑、英语可作为工作语言。

**错误示例（过于冗长）：**
> **金融专业基础扎实:**拥有金融管理本科与企业金融硕士的系统学术训练，核心课程涵盖财务报表分析、估值建模、并购收购、金融衍生品等，具备将财务数据转化为业务判断的知识储备。

**规则：**
- 每行一个特质，不要拆成多行，不要连成一坨
- 小标题选取目标岗位青睐的特质（金融销售→专业基础、客户沟通、执行力、协调能力、抗压自驱）
- 描述要具体有数据，不要泛泛而谈（❌"善于倾听需求" → ✅"参与50+机构客户对接"）
- 不要用圆点列表，不要用冒号后换行
- 最后一行为「工作技能」汇总
