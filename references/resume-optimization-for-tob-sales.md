# ToB 销售简历优化实操指南

## 适用场景

用户要求直接优化简历（非引导式对话），需要将原始经历翻译为 ToB 销售导向的语言。

## 输入素材

1. **原始简历**（PDF/图片/文字）— 提取教育背景、工作经历、项目经历、技能
2. **聊天记录/对话截图** — 挖掘说服案例、沟通风格、真实细节
3. **目标岗位方向** — ToB 金融销售、SaaS 销售、机构客户经理等

## 优化流程

### Step 1: 素材提取

用 pymupdf 提取 PDF 文字：
```python
# 注意：hermes venv 无 pip，用系统 Python
/c/Users/MECHREVO/AppData/Local/Python/pythoncore-3.14-64/python.exe -c "
import pymupdf
doc = pymupdf.open('简历.pdf')
for page in doc:
    print(page.get_text())
"
```

用 winocr 提取图片文字（聊天记录截图等）：
```python
# 同样用系统 Python，注意 sys.path 过滤 hermes venv
/c/Users/MECHREVO/AppData/Local/Python/pythoncore-3.14-64/python.exe -c "
import sys
sys.path = [p for p in sys.path if 'hermes' not in p]
from PIL import Image
import winocr
img = Image.open('聊天记录.png')
text = winocr.recognize_pil_sync(img, 'zh-CN')
print(text['text'].replace(' ', ''))
"
```

### Step 2: 经历翻译（核心）

**翻译公式：** 原始经历 → 底层动作 → 销售语言重写

| 原始表述 | 底层动作 | ToB 销售翻译 |
|----------|----------|-------------|
| 协助整理客户数据 | 数据管理 | 管理客户白名单及路演数据录入，确保数据完整性，支撑客户管理闭环 |
| 安排路演行程 | 协调执行 | 独立协调研究员与客户的时间冲突，确保路演日程高效推进 |
| 建立社群，盈利2w | 从0到1搭建 | 通过「引流→信任→成交」销售漏斗，自主运营4个社群共2000+人 |
| 对接高顿教育合作 | ToB 拓展 | 独立对接头部品牌，用数据打消对方疑虑，促成独家合作 |
| 转化客户700+ | 客户开发 | 精准触达目标客户群体，转化客户700+，累计实现销售5w+ |

**翻译原则：**
- 动词开头（管理、协调、搭建、对接、转化），不用「协助」「参与」
- 补充场景和方法论（不只是做了什么，还有怎么做的）
- 量化结果（数字 + 单位 + 时间维度）
- 杜绝「做了X→得到Y」的空洞叙事

### Step 3: 说服案例独立成段

从聊天记录中提取说服案例，按以下结构组织：

```
- **说服对象：** 谁（客户/合作伙伴/决策者）
- **说服策略：** 怎么做（数据说服/迂回表达/预演逻辑/三级链路）
- **说服结果：** 成了什么（签约/合作/转化/盈利）
```

**案例模板：**
> **说服与影响能力（核心案例）：**
> - **说服合作伙伴：** 主动联系XX公司商务团队，通过展示社群用户质量数据（专业集中度、需求匹配度），说服对方提供资源支持，实现双赢合作
> - **说服决策者链条：** 采用「A→B→C」的三级说服路径，将推广覆盖至目标群体
> - **说服风格适配：** 针对不同性格客户调整策略——对X型采用迂回表达；对Y型提前预演逻辑不留把柄
